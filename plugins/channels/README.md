# 通道调色

给当前这张图的 R / G / B 三个通道分别调整**增益**和**偏置**。它改的只是屏上这份像素，
不写原文件；看腻了用「还原」即可回到原样。

## 怎么用

1. 打开一张图，右键 →「插件」→「通道调色」；或者按你给它绑的快捷键（见下）。
2. 拖动六条滑块（R/G/B 各一条增益、一条偏置）：**看图窗里那张图当场跟着变**，
   右侧数字也同时变，拖着就变、不用松手。
3. 「预设」下拉是一组组滤镜数值（反相 / 提亮 / 压暗 / 高对比 / 柔化 / 暖色 /
   冷色 / 仅红 / 仅绿 / 仅蓝）。选一个，六条滑块立刻摆到对应数值；再拖任一条
   滑块就自动回到「自定义」，可以接着微调。没有「原图」预设——想回原样点
   「还原」。
4. **关掉调色窗就是结束**：没有「完成」「取消」，调好的效果已经在眼前。底部
   「**另存为…**」把当前效果存成 PNG，「**还原**」回到原像素。
5. 每张图各记各的：没调过的图打开就是原图；换到别的图再回来，这张图的调整还在。

## 快捷键与设置

设置页「插件」卡里这一行的**齿轮**是它的设置（目前只有「快捷键」一项）：点进
快捷键框、按下想用的组合键即可。设好之后，在图片上按这把键就等于点菜单里的
「通道调色」。设置页「快捷键」那张卡读的是同一个值，两处改都算。

## 参数

| 参数 | 含义 | 默认 | 滑块范围 |
|---|---|---|---|
| 预设 | 自定义 + 十组滤镜数值（见上） | 自定义 | 下拉 |
| 各通道增益 (%) | 该通道乘以多少，100 = 不变，负数 = 反相方向 | 100 | -400 ~ 400 |
| 各通道偏置 | 乘完再加上多少，可正可负 | 0 | -255 ~ 255 |

每个通道的算法是 `新值 = 原值 × 增益/100 + 偏置`，结果夹在 0–255 之间；透明度不变。

**反相不是另一个效果，就是一组特定数值**：三个通道都是 `增益 = -100`、`偏置 = 255`，
代进去正好得到 `255 - 原值`。所有预设都是这个意思——只是一组写进六条滑块的数。

## 另存为

- 存的是 **PNG**（无损）。编码按体积优先，且全不透明的图不带 alpha 通道，比随手
  截的 PNG 小一截。
- 存的是**整图**，不是屏上那份缩略：窗口缩放、平移都不影响它。
- 目前存不了原格式（JPG / WebP 等）：看图器只内置了 PNG 编码器。

## 限制

- 动图 / 多页文档：显示层调色不挑格式，但「另存为」存的是当前这一帧。
- 结果只存在内存里，不落盘；关掉看图器就没了（原文件从未被改写）。
- 四千万像素那种大图照样能拖滑块调色；「另存为」会为整图另备一份内存。
