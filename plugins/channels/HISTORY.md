# 通道调色 · 版本历史

## 0.1.2 — 2026-11-07 — protocol 1

- 新增第七条滑块「暗部补偿 (Gamma)」：曲线把暗部抬起来、亮部基本不动，范围 30~300
  对应指数 2.0~0.33，100 = 原样。它叠在三通道增益/偏置**之后**，与六条滑块一起生效。
- 预设多一组「暗部补偿」（六数中性 + Gamma 180）；原有十组滤镜数值一字未改。
  预设现在会把七个数一起写回滑块，拖任一条仍自动回落「自定义」。
- 拖 Gamma 时看图窗当场变；「另存为…」把曲线算进整图，「还原」把七个数一起归位。
- 老设置文件与只声明六个数的老清单都不带这一格，像素与 0.1.1 逐字节相同。

## 0.1.1 — 2026-11-06 — protocol 1

- 去掉调色窗的「完成」「取消」：关窗即结束，参数留在当前图上。调色不是保存，不该有
  一次"提交"动作。
- 每张图各自独立：没调过的图打开就是原图；调整按图片记，换图不串、不继承上次的数值。
- 设置页齿轮改成**真正的设置**（目前只有「快捷键」一项），不再用调色滑块冒充设置窗。
  新增快捷键：在图片上按它即打开调色窗。
- 大图不再被 800 万像素上限挡住——调色只作用于屏上那份位图，与整图无关。
- 「另存…」改名「另存为…」，默认文件名取原图主名；编码改为体积优先，全不透明的图
  不再带 alpha 通道。

## 0.1.0 — 2026-11-06 — protocol 1

- 首个版本：R / G / B 三通道独立的增益与偏置，外加「自定义 / 反相 / 原图」三种预设。
- 反相定义为三通道 `增益 -100% / 偏置 255` 这组数值；选它会把数值写回设置，方便接着微调。
- 只改显示、不写原文件，可用「还原原图」撤销；透明度与行尾填充字节保持不变。
- 交互返修：改用宿主声明式参数窗——点插件菜单即弹窗，六项数值是滑块 + 实时读数，
  按「应用」保存并立即重绘；不再要求先去设置页手填 `-100` / `255`。
- 二次返修：manifest 声明 `preview`（`channel-linear`），窗内预览图随滑块实时变色；
  「另存…」「还原原图」收进调色窗，右键菜单不再重复挂；删掉窗口顶部的说明文字。
  插件本体公式未变，靠端到端字节判据保证预览与正式回写一致。
- 三次返修：取消窗内缩略预览图与「应用」按钮——拖滑块时**看图窗本尊**实时变色，
  「完成」只保存参数、「取消」还原开窗前的样子；「另存…」会把同一组参数算进整图。
  预设改为 manifest 的声明式 `presets` 表（去掉「原图」，补上十组滤镜数值），
  宿主选中即写六条滑块，拖滑块自动回落「自定义」。插件本体公式仍未变。
