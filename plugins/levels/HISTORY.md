# levels 历史

> 只记这枚插件**对外可见**的变化：结果内容、manifest 的能力与设置项、随包文件。
> 标题版本 = `manifest.json` 的 `version`，日期 = `plugins.json` 的 `released`。
> **这里不写发布进度**——那些的唯一真源是 `plugins.json`。

## 0.1.6 — 2026-11-06 — protocol 1

- **同日返工：补基线与 0% 刻度**（实机反馈「没有 0%」「横轴底部缺少框线」）：
  水平网格从 `k=1` 起画，`k=0` 那条**底边框线从来没画过**，框只有上/左/右三面；
  纵轴标签同样只印四条，缺 0 起点。现在画满五条水平网格线（底边闭合），右侧
  五条刻度 = 基线 `0.00%` + 峰值的 25/50/75/100%。基线标签坐在底边上方，与横轴
  最右的 `255` 留足间距（否则只隔 3px 还横向叠 6px，会挤成一串）。曲线、统计、
  PNG 编码、协议一字未动；新增单测钉住「底边像素是 GRID」与「基线标签精确为 0.00%」。
- **纵轴改标百分比（峰值自适应）**：横网格线的标签从「绝对点数（K/M 缩写）」
  换成「这一档像素占全图可见像素的百分比」，分母恒为实际统计点数（`counted`，
  跳过 alpha=0），与文本报告里的溢出比例同一份分母。曲线仍按四组峰值箱归一化铺满，
  **顶线 = 本图峰值箱占比**（README 那份样例是 1.37%），不是固定 100%；100% 只是
  理论上限（所有可见像素落进同一箱）。换图、换画幅，刻度仍是同一个量纲，能横着比。
- **刻度字改用亮色**：旧版用网格线深灰画刻度，与背景对比度约 1.7:1，等于没写；
  现在与横轴刻度同为 INK 亮色。3×5 点阵字库补 `%`，去掉不再使用的 K / M 字形。
- **报告补分母与上限**：纵轴那句同时给出点数、占实际统计点的百分比与理论上限；
  绝对点数没有丢，关掉图形时所有数字仍一字不变。
- 统计口径（全量、跳过透明、Rec.601 亮度）、四条曲线画法、PNG 编码、协议、设置项：
  全部一字未动；宿主零改动、依赖树零增长。

## 0.1.5 — 2026-11-04 — protocol 1

- **机器 id 一并改名 `histogram` → `levels`**：0.1.4 只改了显示名，留下
  `histogram`（= 直方图）这个**错名**当目录名、可执行文件名与下载链接的一部分——错名就是错名，机器身份同样不能留。现在四处同时改到底：目录 `plugins/levels/`、
  `manifest.id` = `levels`、产物 `levels.exe`、ZIP `levels_0.1.5.zip`。
- **代价如实记账**：已装目录与设置存储都按 id 分家（`plugins/<id>/settings.json`），换 id
  ⇒ 旧的热键绑定不会自动继承，需要在新条目里重绑一次；旧版本 `histogram_0.1.x` 的下载
  链接保持原样不动（历史产物改名会打断已发出的链接）。
- 显示名「色阶分析」、图形版式、统计口径与文本报告：全部一字未动。

## 0.1.4 — 2026-11-04 — protocol 1

- **显示名「直方图」→「色阶分析」**：0.1.3 起画的是**平滑分布曲线**，"直方"
  （柱状）这个名字早已名不副实；"色阶"（Levels）正是亮度与三通道分布这一套东西的专业
  叫法，涵盖曲线上的一切读法——曝光、对比度、偏色。取名按专业性，故不取"像素分析/明暗分析"这类泛称。
  本轮只改**显示名**与结果窗标题、设置项文案；机器 id 在下一版一并改（见 0.1.5）。
  顺带：结果窗标题 `## 直方图` → `## 色阶分析`，设置项「同时生成图形直方图」→
  「同时生成分布曲线图」。图与统计口径零变化。

## 0.1.3 — 2026-11-04 — protocol 1

- **版式回定为"一张图叠四条曲线"**：0.1.0 看不清的**真凶是曲线下的面积
  填色**（限幅相加把重叠区搅成混色），不是叠加本身。取消面积色、只画**纯色细描边**
  （2 像素 + 列间落差补线）后，四条 Catmull-Rom 平滑曲线重叠在同一绘图区也能一眼分清。
  画布 640×720 → **640×360**；顶部一行图例（色块 + 字母）。横轴 5 档刻度
  （0/64/128/192/255）与纵轴右侧**绝对点数**（K / M 缩写，顶线 = 全局峰值）保留。
  统计口径与文本报告一字未动；单测改钉「曲线下方必须是无面积色的干净背景」。

## 0.1.2 — 2026-11-04 — protocol 1

- **曲线平滑**：每像素列取一次 **Catmull-Rom 样条**插值（过数据点、手写 ~30 行，
  零依赖），阶梯感消除；淡填充 + 顶部纯色描边不变。**统计口径与文本报告一字未动**——
  平滑只作用在画图上，箱值、均值、溢出比例全是原数。
- **刻度**：横轴 3 条网格线 → **5 条**（0/64/128/192/255，数值写在最底格下方）；
  纵轴右侧新增**绝对点数**刻度（四条横网格线各标一个，万级以上缩写 K / M，
  顶线 = 全局峰值）。绘图区 580→右移让位给数值标签。
- **打开方式**：随宿主同日变更，`open_image` 的图由宿主**开新看图窗口**显示
  （不再交系统默认程序——系统关联到 RuPix 自己时会顶掉用户正在看的图）。

## 0.1.1 — 2026-11-04 — protocol 1

- **图形版式重画（四条曲线叠在一起时颜色不易区分）**：从"一张图叠四条实心柱"改为
  **四格竖排、每格一条通道曲线**——淡色填充 + 顶部两像素纯色描边，格与格之间互不叠混，
  任何颜色都能一眼认出是谁。四格 x 轴对齐、**共用同一纵轴**（满格 = 全局峰值箱），
  "哪一通道堆在哪一侧"仍可上下横向比；横轴刻度 0/128/255 只写在最底格。
  画布 640×360 → **640×720**，其余（统计口径、文本报告、读法）一字未动。

## 0.1.0 — 2026-11-04 — protocol 1

- **新增**：第三枚官方插件、第一枚出图的插件。对当前图片全量统计 R / G / B / 亮度四组
  256 箱，结果窗给出一段 Markdown：统计范围与实际点数、亮度均值 / 中位数箱 / 峰值箱、
  暗部（0–5）与高光（250–255）溢出点数与占比、三通道均值与偏色提示、读法与纵轴口径。
- **图形**：插件自己画一张 640×360 的 RGBA 直方图——四条曲线共用同一纵轴，
  红=R / 绿=G / 蓝=B / 白=亮度，带 25/50/75/100% 网格、`0 / 128 / 255` 刻度与图例字母；
  通过协议 v1 现成的 `open_image` 通道回传，**不需要宿主为它新增能力**。通道边界如实写进
  README：图由宿主落到 `<exe>/temp/` 后交**系统默认看图程序**打开，不是 RuPix 窗口内嵌。
- **零新增依赖**：只 link `serde_json` + `windows`（与 `checkup` 相同）。画图是往 RGBA
  缓冲填矩形，PNG 用手写 `zlib stored-deflate` + Adler-32 + CRC-32 + IHDR/IDAT/IEND，
  base64 也是手写的——没有 `png` / `flate2` / 图表库 / SVG 引擎 / 字体文件。
  这一条直接回答了"自己画图是不是需要额外工具"：不需要。
- **读数纪律**：不抽稀（8 MP 以内全量，报告印实际点数）；`alpha=0` 像素不计入
  （屏幕上那是棋盘格不是图像颜色，报告印跳过多少点）；亮度公式写死为
  `(77R+150G+29B)>>8`（Rec.601 整数近似，与 `checkup` 同款）；峰值平票取小箱号。
- **能力**：`image.read`、`settings.read`、`settings.write`、`open.file`（最后这一条是
  宿主采纳 `open_image` 的前提）。
- **设置**（宿主按 manifest 渲染的设置窗，值存 `plugins/levels/settings.json`）：
  「同时生成图形直方图」勾选，默认**开**，关掉只出文本、不弹外部看图程序；
  「快捷键」出厂**空**。关掉图形**不改任何一个数字**。
- **失败形状**：拿不到整图（切片态 / 超过 8 MP）、整图全透明时如实报错退出，
  不画空图、不假装"分布正常"。
- **随包文件**：`histogram.exe`、`manifest.json`、`README.md`、`LICENSE`（MIT），
  以及构建时生成的 `LICENSE-NOTICE.md` 与 `THIRD-PARTY-NOTICES.md`。
- **验证**：单测覆盖亮度公式、分箱落点、透明跳过、平票与中位数、溢出计数、报告口径、
  PNG 签名/CRC/Adler/stored 多块往返、base64 已知向量、纯红与纯黑夹具的柱子位置、
  设置开关、未知 action、缺像素、帧长度闸；另有迷你宿主协议探针做端到端。
- **图形可见性（同日）**：宿主侧修正了回传图片的落盘后缀，系统按图片关联打开，图形直方图
  现在能正常显示；本插件输出与随包字节未变，无需重新发布 ZIP。
