# scan（条码识别）

识别**当前打开的图片**里的条码与二维码，把内容原样给你。它是"图进、内容出"的
`command` 型插件：不开窗口、不解码文件、不联网、不写任何地方；**默认也不替你执行任何载荷**
（只有你在设置里勾了"直接打开"，才由宿主去开，见下文）。

支持哪些码由解码器决定（ZXing 的 Rust 移植 `rxing`）：QR、DataMatrix、Aztec、PDF417，
以及 UPC/EAN、Code 39/93/128、ITF、Codabar 这些一维码。

## 拿到的是什么

宿主在请求里给一块共享内存整图（协议 v1 §3 `image` + §5 布局），插件只读打开。
★ 扫的是**屏上朝向**那一份（已按旋转/镜像转正）——所以一张竖拍的照片不需要你手动转。
只有本插件声明了 `image.read`、且整图不超过宿主的编辑档上限（8 MP）时宿主才下发像素；
拿不到像素时**如实报错**，不假装"没找到码"。

## 结果长什么样

一枚码三行——`格式 / 类型 / 内容`，类型专属的字段跟在后面（Wi-Fi 的名称·加密·密码，联系人的
姓名·电话·邮箱）。多枚码之间空一行。**没有**标题、"找到 N 枚码"、定位点数、扫描尺寸这类外壳。

```
格式：QR_CODE
类型：文本
内容：你好啊
```

```
格式：QR_CODE
类型：WiFi
名称：Cafe-Guest
加密：WPA
密码：s3cr3t-pass
```

装的是图片（码里塞了一张 PNG/JPG 之类）时，内容行换成一行事实：`图片：PNG，1234 字节`；
认不出是什么就只报 `二进制：1234 字节`。**默认不打开也不落盘**——要不要真开，见下面
「两个可勾选的"直接打开"」。

只有两种情况会多一句话：**一枚都没找到**（沉默会让你以为点了没反应）、**降采样过**
（那时扫的不是原图）。

★ **密码照实显示**：二维码本身就在同一扇屏幕上看得到，遮住从它解出来的文本保护不了什么，
只会让你没法照着连 Wi-Fi。（第一版只报位数，信息不足。）

## 两个可勾选的"直接打开"

设置里有两项（默认都**不勾**）：

- **解码后直接打开网址**：扫到 `http(s)` 网址就用系统默认浏览器打开；
- **解码后直接打开图片**：码里装的是光栅图（PNG/JPG/GIF/BMP/WebP/TIFF/ICO）就写进
  宿主的 `<exe>/temp/`，由宿主开**一个新的看图窗口**显示（2026-11-04 起不再交系统
  关联——关联到 RuPix 自己时会顶掉正在看的图）。

两条都走**宿主的**打开通道（`open.url` / `open.file`）：宿主先验（网址只认 http(s)；
图片按**文件头**复核，不认插件自称的后缀）再打开。一次只开**第一枚**命中的码——
弹三个窗口不叫帮忙。

## 两枚码贴太近会漏

解码器要求相邻两枚码之间**每侧至少 4 个模块**的静区。截图里两枚码只隔一条细缝时，
可能只认出一枚——这是解码库的前置条件，不是本插件的取舍（实测：260px 的码之间留 40px
只认一枚，留 90px 就两枚都认）。

## 大图会先降采样

超过 200 万像素的图按整数步长**盒式（面积平均）**降采样后再扫，并把"实际扫了多大、
步长几"印在报告里。这是**超时预算**（宿主 30 s 判超时），不是画质档：条码本身不需要
800 万像素，裁近一点识别率反而更高。

## 构建

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File build.ps1
```

产物写到工作区 `.temp/plugin-dist/scan/`（`scan.exe` + `manifest.json`）。
依赖里 `rxing` 关掉了默认特性（`image` / `image_formats` 会拖进一整套图片解码栈，而像素是
宿主给的，插件不解文件）——这笔账登记在仓库根 `THIRD-PARTY-NOTICES.md` §二。

## 冒烟（不用开 GUI）

```powershell
cd <宿主>\main
set RUPIX_DECODERS_DIR=<工作区>\.build\decoders
cargo run --release --example plugin_smoke -- ..\.temp\plugin-dist\scan <一张带码的图片>
```

探针第二腿会用宿主自己的解码栈真解那张图，把真实像素经共享内存送进来，报告打到 stdout。
单测里另有"自己生成码再解回来"的往返用例（含一张图两枚码），不依赖任何外部样张。
