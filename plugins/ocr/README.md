# OCR 文字识别

对**当前打开的图片**做离线文字识别，回一段纯文本；宿主自动把这段文本复制进剪贴板，
可以直接 `Ctrl+V`。不开窗口、不联网、不上传图片、不改原图。

## 能识别什么（先看这一节）

**一次识别、不用选语言：中文（简体 / 繁体）、英文、数字、常见标点与符号。**

简体与繁体在 Unicode 里用的是同一批 CJK 汉字码位，识别字典里本来就不分家；
英文、数字与常见符号也在同一本字典里。所以简繁英混排的一张图，一次就全出来。

| 类别 | 字典里有什么 | 实际表现 |
|---|---|---|
| 简体中文 / 繁体中文 | 6270 个 CJK 统一汉字 | 常用繁体字绝大多数能读；`繁體中文測試臺灣網路` 实测一行全对 |
| 英文 / 数字 / ASCII 标点 | 94 个 ASCII 可打印字符 | 中英数字混排一次全出 |
| 繁体特有字 | 常用字大多在 | 极少数如 `擊` / `螢` 不在字典里，会漏或认成近似字 |
| 希腊字母 | 10 个：`α β ε θ μ π Λ Ο Φ Ω` | 简单字形能认，不是完整希腊字母表 |
| 数学符号 / 箭头 | 15 / 5 个：`∑ √ ∞ ≠ ≤ ≥ ∫ ≈ ∈ ∩ ⊙ ⊥ ∧ ∣ ∶`、`→ ← ↑ ↓ ⇋` | 笔画复杂的常认错 |
| 全角与 CJK 标点 / 常见符号 | 85 / 23 个，另有 `± § ° ※ ★ ● ① ② ③ ℃ № ‰ ¥ ￠ ￡` 等 | 截图里偶尔带一个够用 |
| 拉丁扩展（带声调字母、`×` `÷`） | 24 个 | 无重音的词能读，带 `ç ê ù` 会掉字 |

★ **不支持日文、韩文，也不支持俄语等西里尔文字、法语等带重音的拉丁语系**：
假名、谚文、西里尔字母所需的识别模型没有随包（字典里谚文 0 个、假名 5 个）。
拿它扫这些截图只会出乱码——这是能力边界，不是设置问题。

★ **「字典里有」不等于「一定认得出」**：端到端实测一张白底黑字的符号行
`α β ∑ √ → ± ℃ ①`，输出 `αβM<→` —— 希腊字母、箭头这类简单字形能认，
`∑ √ ± ℃` 常认错或漏掉。别拿它抄公式；符号只是「中英文截图里偶尔带一个」的兜底，
不是本插件的主用途。

字典是训练时定死的，**改字典加字符不会多认字，只会让整行解码错位**。
所以上表是「实际已经有什么」，不是「可以加什么」。

## 为什么不用选语言

识别一次只能挂一套字典，但这一套已经同时装了简、繁、英。曾经给过一个
「默认 / 繁体专用」二选一，实测得不偿失：

| 实测 | 结果 |
|---|---|
| 繁体图 + 本版字典 | `繁體中文測試臺灣網路` 一行全对；第二行只漏 `擊` / `螢` |
| 繁体图 + 繁体专用模型 | 两行全对（只多认那两个字） |
| 简体图 + 繁体专用模型 | `正品促销` → `正品促銷`、`划算` → `切算` |

为两个字典外的字让用户先判断图片是简是繁，还会把简体翻成繁体，不划算；
两套一起跑又没有依据判断哪份结果对。所以本版只带一套，**不做语言开关**。

## 数据从哪来、边界在哪

宿主把**屏上朝向**的整图像素放进共享内存，本插件只读打开，合成白底后写成一张临时
PNG 交给随包的引擎，跑完立刻删掉临时文件。

- 只有声明了 `image.read`、且整图不超过宿主 **8 MP** 上限时才有像素。超限时宿主只给路径，
  本插件**如实报错退出**，不把「没扫过」说成「没识别出文字」。
- 本插件**不声明** `image.sampled`：等距抽样会把笔画跳掉，抽样图上的 OCR 等于没做。
- 透明像素按白底合成，避免透明区域的残留 RGB 把文字糊掉。

## 设置（齿轮 → 宿主渲染的设置窗）

| 键 | 界面 | 取值 |
|---|---|---|
| `hotkey` | 「快捷键」捕获框 | 出厂**空**，不抢用户的键 |

没有别的设置项；识别不需要用户先判断语言。

## 失败会说人话

包没装全（五个引擎/模型文件缺任何一个）、引擎起不来 / 退出码非 0 / 超过 25 秒 /
框里没有可读文本行，都会给一句能照做的中文原因，不静默回空串。
结果窗里的 `text` **只放纯识别结果**：说明文字不混进复制内容，免得 `Ctrl+V` 粘出一行注解。

## 构建

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File build.ps1
```

产物写到工作区 `.temp/plugin-dist/ocr/`：`ocr.exe`、`manifest.json` 与
`engine/`（引擎 + det / cls / rec 模型 + 字典，共 5 个文件）。
`fetch_assets.py` 按固定 URL 下载并逐个校验 SHA256，**仓库里不放任何二进制**；
已校验过的资产会复用缓存，不重复下载。

## 冒烟（不用开 GUI）

```powershell
cd <宿主>\main
set RUPIX_DECODERS_DIR=<工作区>\.build\decoders
cargo run --release --example plugin_smoke -- ..\.temp\plugin-dist\ocr <一张含文字的图片>
```
